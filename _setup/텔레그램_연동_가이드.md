# 견적 요청 → 텔레그램 알림 연결

고객이 사이트에서 **구매 요청 보내기**를 누르면 텔레그램으로 알림이 오게 만드는 설정입니다. 15분 정도 걸립니다.

## 왜 중계가 필요한가

텔레그램 봇 토큰을 사이트 코드(`products.js`)에 바로 넣으면, 공개 저장소라서 누구나 토큰을 보고 봇을 마음대로 쓸 수 있습니다. 그래서 토큰은 **Google Apps Script**(무료, 구글 계정만 있으면 됨)에 숨겨 두고, 사이트는 그 주소로만 요청을 보냅니다.

```
고객 브라우저 → Apps Script (토큰 보관) → 텔레그램 봇 → 담당자 텔레그램
```

---

## 1. 텔레그램 봇 만들기

1. 텔레그램에서 **@BotFather** 검색 → 대화 시작
2. `/newbot` 입력
3. 봇 이름 입력 (예: `클라우드에어 견적 알림`)
4. 봇 아이디 입력 — `bot`으로 끝나야 함 (예: `cloudair_quote_bot`)
5. 받은 **토큰**을 복사해 둡니다 — `1234567890:AAH...` 형태

토큰은 비밀번호와 같습니다. 채팅방이나 저장소에 올리지 마세요.

## 2. 알림 받을 채팅 ID 확인

**혼자 받을 때**

1. 방금 만든 봇을 검색해 대화방을 열고 아무 메시지나 보냅니다 (예: `안녕`)
2. 브라우저 주소창에 아래를 입력 (`<토큰>` 자리에 1번에서 받은 토큰)

   ```
   https://api.telegram.org/bot<토큰>/getUpdates
   ```

3. 나오는 글에서 `"chat":{"id":123456789` 의 **숫자**가 채팅 ID입니다

**팀 단톡방에서 같이 받을 때**

1. 텔레그램 그룹에 봇을 초대하고 그룹에서 아무 메시지나 보냅니다
2. 위와 같은 주소로 확인 — 그룹 ID는 `-100...` 처럼 **마이너스로 시작**합니다. 마이너스까지 전부 복사하세요

`getUpdates` 결과가 `"result":[]`로 비어 있으면, 봇에게 메시지를 한 번 더 보낸 뒤 새로고침하세요.

## 3. Apps Script 만들기

1. **script.google.com** 접속 (회사 구글 계정으로 로그인) → **새 프로젝트**
2. 제목을 `견적기 텔레그램 중계`로 바꾸기
3. 기본 코드를 전부 지우고, 이 폴더의 **`Code.gs`** 내용을 통째로 붙여넣기 → 저장

## 4. 토큰과 채팅 ID 저장

1. 왼쪽 **톱니바퀴(프로젝트 설정)** → 맨 아래 **스크립트 속성** → **스크립트 속성 추가**
2. 두 개를 추가하고 **저장**

   | 속성 | 값 |
   | --- | --- |
   | `BOT_TOKEN` | 1번에서 받은 토큰 |
   | `CHAT_ID` | 2번에서 확인한 숫자 |

## 5. 연결 테스트

1. 왼쪽 **편집기(`<>`)**로 돌아가서, 위쪽 함수 선택 칸에서 **`testSend`** 선택 → **실행**
2. 처음 실행하면 권한 확인 창이 뜹니다
   - **권한 검토** → 구글 계정 선택
   - "Google에서 확인하지 않은 앱" 화면이 나오면 **고급** → **(안전하지 않음)으로 이동** → **허용**
   - 본인이 만든 스크립트라 뜨는 정상 절차입니다
3. 텔레그램에 `[테스트] 견적기 텔레그램 연결이 정상입니다.`가 오면 성공

안 오면 실행 로그를 보세요. "전송 실패"면 토큰이나 채팅 ID가 틀린 것입니다.

## 6. 웹 앱으로 배포

1. 오른쪽 위 **배포** → **새 배포**
2. 유형 선택 톱니바퀴 → **웹 앱**
3. 설정
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** → 나오는 **웹 앱 URL** 복사 — `https://script.google.com/macros/s/.../exec` 형태

## 7. 사이트에 연결

`products.js` 맨 위쪽의 이 줄에 6번 URL을 붙여넣습니다.

```js
telegramRelayUrl: "https://script.google.com/macros/s/.../exec",
```

그다음 평소처럼 올리면 끝입니다.

```powershell
git add .
git commit -m "텔레그램 알림 연결"
git push
```

## 8. 실제 요청 테스트

1~2분 뒤 사이트에서 서비스를 하나 담고, 이름·소속·이메일을 넣고 **구매 요청 보내기** → 텔레그램에 이런 메시지가 오면 완료입니다.

```
[AI 구독 견적 요청] 2026-09-29 18:30

OO대학교 홍길동
이메일 name@example.ac.kr

1. ChatGPT Plus · 2계정 · 12개월
2. Claude Pro · 1계정 · 6개월
```

## 알아두실 점

- **URL이 설정되기 전**에는 고객이 보내기를 누르면 "지금은 온라인 요청을 받을 수 없습니다. 이메일로 연락 주세요"라고 안내됩니다.
- `Code.gs`를 고쳤다면 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포**를 해야 반영됩니다. 이렇게 하면 URL은 그대로 유지됩니다. "새 배포"를 다시 누르면 URL이 바뀌니 주의하세요.
- 스팸 방지를 위해 10분에 30건이 넘으면 잠시 요청을 막습니다. `Code.gs` 맨 위 `MAX_PER_10MIN` 숫자로 조절할 수 있습니다.
- 봇 토큰이 노출됐다고 생각되면 @BotFather에서 `/revoke`로 토큰을 새로 받고, 스크립트 속성의 `BOT_TOKEN`만 바꾸면 됩니다.
